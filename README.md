# CodeLingo Backend

Node.js + Express + PostgreSQL backend using Drizzle ORM and TypeScript.

## Prerequisites

- Node.js 20+
- npm
- PostgreSQL

## Setup

Install dependencies:

```bash
npm install
```

Create your local environment file:

```bash
cp .env.example .env
```

Update `DATABASE_URL` in `.env` to point at your PostgreSQL database:

```env
DATABASE_URL=postgres://postgres:postgres@localhost:5432/codelingo
PORT=3000
JWT_SECRET=replace-with-a-secure-random-secret
```

Create the local PostgreSQL database manually if it does not exist yet:

```bash
createdb codelingo
```

If your PostgreSQL user, password, host, or port are different, update `DATABASE_URL` accordingly.

## Database Migrations

Generate a migration from the Drizzle schema:

```bash
npm run db:generate
```

Apply migrations:

```bash
npm run db:migrate
```

The example schema includes a `users` table with auth, profile, gamification, language, and dashboard metric fields. User IDs are generated by the application with CUID2 when inserting through Drizzle.

## Development

Start the development server with hot reload:

```bash
npm run dev
```

Health check:

```bash
curl http://localhost:3000/health
```

Auth API:

```bash
curl -X POST http://localhost:3000/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Ada Lovelace","email":"ada@example.com","password":"secret123"}'
curl -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"ada@example.com","password":"secret123"}'
```

## AI Chat

`POST /chat` requires a bearer token and accepts an optional short history:

```bash
curl -X POST http://localhost:3000/chat \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"message":"Explain a for loop","history":[{"role":"user","content":"I am new to Python"}]}'
```

Progress questions such as "How was my last week?" return a deterministic quick
summary from the user's saved data. Other questions use `OPENROUTER_API_KEY`,
`OPENROUTER_CHAT_MODEL` (default `xingchen-agi/xing4.0-29b-a4b:free`), and
`OPENROUTER_FALLBACK_MODEL` (default `openrouter/free`). Both are free models;
reasoning is disabled for chat. Chat is limited to 20 messages per hour and 60
per day per user, plus `CHAT_DAILY_GLOBAL_LIMIT` (default 500) messages per day
across all users. Upstream OpenRouter rate limits also return a friendly 429.
